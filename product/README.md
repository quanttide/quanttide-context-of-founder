# 产品

产品线的意图与未决事项。日志归 `data/journal/product/`，本集只留定义、意图与待办。

## 目录

- `intention/`：产品意图草稿，成熟后迁往意图仓 `data/intention/`。
- `TODO.md`：本集未决事项。

## code 与 product 的边界

- product：做什么产品、给谁、分几层交付。产品定义、意图与验收标准留在这里。
- code：怎么写、代码放哪个仓、用什么命令与工具。实现方案归代码资产仓或对应项目仓。
- 同一件事两边都涉及：定义在 product，实现在 code，互链不复制。

## 来源

本集内容从工作日志提炼，单次事件与业务状态留在日志里。
